# 网页录入精简 · 2026-10-28

## 当前行为

本轮沿用网页调整范围。常用录入仅保留目标、任务、日常记录与早中晚回顾；模型、布局、定时分析等技术设置仍保留。

- 设置撤下展示资料、个性与协作偏好、日程提醒的填写表单。设备配对和 Agent 授权保留，新增授权范围选择不再展示私人画像/提醒读取项。
- 独立想法录入与想法库标签撤下，页面改名“日志与任务”。旧想法在任务列表以“待定任务（原想法）”显示，未自动转成正式任务，历史数据不重写。
- 活动日志不再提供添加/更正表单或“其他已完成事项”录入。总览快捷记录只保存普通记录；任务旁进入任务详情更新。
- 新增“任务动态”：从已保存的任务版本自动推导创建、状态变化、内容/计划日期/类别修改。仅表示系统内操作，不推断线下完成事实。日志只读，不写入重复事件。
- 旧活动日志在“历史活动记录”折叠区及全内容查询中保留。新动态可打开对应任务来源与完整修订。

## 实现

`GET /api/task-events?day=YYYY-MM-DD` 与其他网页接口共享认证，按上海时区的实际修订日期筛选；编号为任务编号加版本，重复查询不会重复保存。只有已确认的任务版本参与，拒绝/待确认提案和旧想法不计入。数据恢复后可由原任务历史重建，无迁移。

文件：`src/personalai/history_routes.py`、`frontend/src/TaskEvents.tsx`、`Dashboard.tsx`、`main.tsx`、`QuickEntry.tsx`、`SettingsPage.tsx`、`ClientPanel.tsx`。

## 范围与发布注意

这是网页录入入口精简，不删除历史资料，不移除服务器兼容接口，不更改 APK。现有服务器/手机提醒规则未被自动撤销；若要跨端完全退役提醒，需另行清点既有规则与设备缓存。定时 AI 分析与日程提醒是不同功能，本轮保留前者。
