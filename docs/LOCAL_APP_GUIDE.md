# PersonalAI 本地应用 v0.1 使用说明

更新：2026-10-23。当前里程碑提供可靠记录基础，尚未接入云端模型。

## 启动与停止

在项目目录的 PowerShell 中运行：

```powershell
.\Start-PersonalAI.ps1
```

在电脑浏览器打开 `http://127.0.0.1:8765/`。保持启动窗口运行；按 `Ctrl+C` 停止。

默认端口不可用时，程序会明确报错，不会关闭占用端口的服务或自动改端口。可以指定另一个本机端口：

```powershell
.\Start-PersonalAI.ps1 -Port 18765
```

然后打开 `http://127.0.0.1:18765/`。本次浏览器验收使用 18765；8765 当时无法绑定。应用只监听 `127.0.0.1`，不会开放局域网或公网，也不设置开机启动。

首次安装或重新建立开发环境时运行：

```powershell
.\Setup-PersonalAI.ps1
```

需要 Python 3.12 或更高版本、支持项目依赖的 Node.js 和 npm。安装使用项目内 `.venv`、Python 版本锁及 npm 锁文件；不修改系统 Python 的包。安装依赖需要联网，但不会上传个人资料。程序日常运行不调用外部服务。

如果组织策略阻止 PowerShell 脚本，请遵循已有设备策略；不需要为本应用全局降低执行策略。可在终端直接运行：

```powershell
.\.venv\Scripts\python.exe -m personalai --port 18765
```

## 四个入口

- **对话记录**：保存输入原文，可手动选择日期和类别。十类信息均可缺失。“日常记录”不会自动生成正式任务；选择“正式任务”或“想法”后保存，是用户的明确创建操作。
- **历史记录**：按日期、类别和文本检索。点击记录查看来源与历史版本。点击“提出更正”，填写内容和原因，再查看前后差异，最后确认或拒绝。
- **计划与建议**：分别查看正式任务、想法和待确认事项。修改任务的内容、日期、类别或执行状态同样需要确认。过期提案不能覆盖新版本；可以拒绝旧提案，再重新提出修改。
- **每日汇总**：展示指定日期已有的用户记录；按手动类别分组，任务独立呈现。未记录的类别显示“未记录／无法判断”。这是事实材料汇总，不是已核实事实、表现评价或完整 AI 日报。

一段输入包含多项经历时，当前版本保存整段原文及一个手动类别，不声称自动提取多个指标。精细拆分与自然语言意图识别需要后续模型适配。自然语言日期不会从正文自动推断；界面的日期选择器以服务器提供的上海日期作为初值。查询接口支持“今天／昨天／明天”等上海日期别名。

## 数据与隐私

- 默认运行数据位于项目的 `data/events/`。每个 Markdown 文件是一笔不可拆分的修订事务；元数据包含记录编号、来源、时间、版本、请求编号和校验值，下方保留可阅读内容。
- 同一记录的旧版保留在之前的事务中，查询时重建当前视图。不依赖专有数据库。
- 确认提案和最终记录在同一事务中提交；文件写入使用锁、临时文件和原子替换。
- 不要手工编辑运行中的事件文件。校验失败时应用停止提供记录查询、汇总和写入，显示文件异常，避免基于残缺数据继续分析。
- 原有 `personal/`、全局个人档案及需求文档不会被应用自动读取、改写或同步。
- `.gitignore` 排除个人档案、运行数据、缓存、备份和凭据。当前未创建远端仓库、未上传代码或资料。排除规则不能撤回已经被其他工具公开或跟踪的数据。
- 本阶段没有模型服务、密钥输入框或网络调用。配置示例仅说明默认状态，不会读取并启用模型服务。

## 备份与恢复

点击“备份与恢复校验”（宽窗口在左下角，窄窗口在顶栏）：

1. **导出备份**：保存应用的记录、修订与确认日志，附 SHA-256 文件清单；导出前在临时目录验证恢复。请确认浏览器下载成功，主动将备份保存到独立位置。
2. **校验已有备份**：选择 ZIP 文件，仅上传到本机服务；检查清单和事件链，在独立临时目录恢复，返回记录数及事件数。不会覆盖现有数据。浏览器校验上传限制 32 MB，解压后内容限制 256 MB。

备份不包含原有个人档案、程序或配置，这些应由你已有的文件备份方式另外保护。SHA-256 校验用于检测损坏，不是加密或防恶意伪造机制。

如需恢复文件，命令行只允许写入一个尚不存在的新目录：

```powershell
.\.venv\Scripts\python.exe -m personalai.backup 'D:\PersonalAI-Backups\backup.zip' --restore-to 'E:\PersonalAI-Restored'
```

以上路径是示例，需要替换为实际位置。原运行目录不会被覆盖。恢复后先核对，再显式选择恢复目录启动：

```powershell
.\.venv\Scripts\python.exe -m personalai --port 18765 --data-dir 'E:\PersonalAI-Restored'
```

只验证而不保存恢复文件，可省略 `--restore-to`。周期自动备份、保留策略和覆盖恢复不在当前里程碑内，尚未配置。

## 常见情况

- **模型尚未配置**：属于当前版本的明确状态，保存原文和手动查询仍可使用；没有伪造 AI 输出。
- **保存失败**：输入框保留当前文字；在当前页面重试相同内容沿用同一请求编号，防止请求结果丢失造成重复保存。刷新页面会丢失尚未保存的输入，应先复制保留。
- **会话失效**：复制未保存内容后刷新页面；服务重启会使旧的写入会话失效。
- **修改过期**：已有更新版本，拒绝旧提案并基于最新记录重新修改。
- **文件校验失败**：停止写入，保存当前目录副本，使用已验证备份恢复到新目录核对；不要直接删掉提示的文件来消除错误。

## 开发验证

```powershell
.\.venv\Scripts\python.exe -m pytest -q
Push-Location frontend
npm.cmd run build
Pop-Location
```

自动测试全部使用临时目录和虚构输入。浏览器验收的虚构数据在 `.cache/browser-qa/`，与默认 `data/` 分离；该目录被版本控制排除。浏览器验收下载的 ZIP 内容也都是标注“虚构验收”的测试记录。
