# 电脑版 v0.2：实现与验证记录

日期：2026-10-24（Asia/Shanghai）。按用户已批准的 v0.2 计划实施。本文件补充实现情况，不改写原有访谈、需求与阶段路线。

> 本文保留首次实现时的历史验证结果。后续已完成独立浏览器验收，最新状态见 [README.MD](../README.MD)；下文测试目录、服务状态及浏览器阻碍均指首次交付当时。本地交接原件不随公开仓库发布。

## 已实现

- 保留 v0.1 对话记录、历史、任务／想法、修订确认、事实汇总和备份功能，新增总览与设置。
- 总览模块：个人展示资料、带日期的状态、年度时间、目标与任务横条、活动日志、其他完成事项、早中晚回顾、待确认和已处理事项。模块支持顺序调整及隐藏，页面有电脑、平板、手机宽度的布局规则。
- 目标采用数值指标或带权重的里程碑，未知不等于零。任务自身进度独立，不用完成任务数量推算目标完成度。
- 新建日志可附带追踪进度提案，在一个事务中保存日志与提案；拒绝进度调整不会丢失日志。正式变更仍需差异确认，旧版保留，过期提案不能覆盖新版本。
- 早中晚回应与任务日志可按日期回看；无目标的已完成事项单独展示。没有提醒推送、外部应用写入或入站消息同步。
- 导出 Markdown／JSON，支持日期、时段和目标筛选、预览与下载。目标和任务为当前快照；日期、时段筛选日志与回应。
- 设置包含手动展示资料、任务类型及停用、模块顺序、模型配置、密钥、虚构连接测试、数据位置与帮助入口。
- 模型通过可配置的 Chat Completions 接口分析目标，默认关闭。用户明确选中并预览资料后才调用；输出经过字段、区间、真实来源编号及活动证据检查。分析引用版本变化后显示过期状态。
- 已确认进度和 AI 估计分开展示；AI 建议有待确认／接受／拒绝状态。接受建议本身不创建任务，也不修改计划。
- 密钥由 Windows 当前账户 DPAPI 保护，并绑定服务地址；不进入事件、导出或备份。密钥丢失或无法解密不会阻止访问本地记录和设置。
- README 已整理为安装启动、使用流程、模型配置、数据备份、故障排查和能力状态入口；原交接内容保存在 `HANDOFF_ORIGINAL.md`。

## 兼容与权限

原 Event／Record 类型未增删字段。新类型使用 EventV2，旧版和新版共用校验链、跨进程写入锁、原子替换与请求去重。历史事件不批量重写。原备份返回格式保持兼容，新实体与设置随事件自动进入备份。

仍只监听 127.0.0.1，并检查 Host、Origin、会话 cookie 与写请求令牌。静态服务只提供构建后的首页与资源，不开放项目文件目录。模型仅由后端调用，密钥不回显、不进入浏览器持久存储。模型结果经过服务层保存，模型不能直接写文件。

旧版需求文档与 personal/ 文件未改写，应用不自动读取完整私人画像。正式 data/events/ 未被验收数据写入。

## 验证证据

### 已验证：自动化与实际本机 HTTP

- 后端 **63 项自动测试通过**，包含原有 35 项回归及新增场景：混合版本读取、逐文件备份恢复、增减型指标、里程碑、未知进度、大数值计算、闰年跨年、拒绝与过期确认、请求去重、任务类型停用、筛选导出、日志与进度提案原子写入、写入中断、数据损坏、密钥保护及损坏恢复。
- TypeScript 检查与 Vite 生产构建通过。前端已拆分总览、设置、编辑表单、确认展示、分析预览和导出模块。
- 使用独立 `.cache/browser-v02/` 虚构数据目录启动本地服务，实际 HTTP 验证创建 2 个目标、1 个任务、2 条活动日志、3 条早中晚回应和当前状态。数值目标返回 30%，缺失里程碑数据的目标返回未知；日志保存后任务保持 40%，确认附带提案后变为 50%。
- 实际 HTTP 验证 Markdown／JSON 按目标筛选；无关目标的其他事项未进入导出。首页及构建资源返回 200；私人路径返回 404；跨站写入返回 403。
- HTTP 导出备份并重新提交校验，在独立临时目录恢复成功，包含 1 条原版任务记录、13 个混合版本事务。运行摘要位于忽略版本控制的 `.cache/v02-http-summary.json`。
- 本地安装元数据已更新为 0.2.0。停止并重新启动测试服务后，目标、任务进度、日志、三次回应与展示设置均可回查；正式 data/events/ 仍为空。交付时保留本地虚构演示服务，地址为 http://127.0.0.1:18765/，数据目录仍为独立测试目录。
- 测试输出有一条 Starlette 对旧 httpx TestClient 适配的弃用提示，未影响测试通过；本次不为消除提示更换测试框架。

### 已验证：模型接口模拟

测试仅使用虚构输入和内存 MockTransport，不连接外部服务。覆盖显式资料选择、数据版本过期、来源校验、缺少日志依据、无效区间、拒绝回答、错误 JSON、429、超时、重定向和请求去重；失败不会保存分析或改变正式目标。连接测试只发送虚构样例，不使用真实目标资料。

### 尚未验证

- **浏览器实际交互和视觉布局**：浏览器控制工具多次返回 `transport closed before response`，重置连接仍失败，随后工具不可用。未完成 v0.2 点击流程、截图、浏览器控制台检查和电脑／平板／手机视口验收。HTTP 200 与构建通过不代表这些项目已验收。
- **真实模型服务**：没有配置供应商凭据，未发起真实模型请求；接口兼容性、费用、速度和估计质量均需在用户本地配置后验证。

## 后续与限制

- 未实现外网访问、身份系统、跨端同步、自动提醒、周期备份、完整智能日报或自动理解所有对话输入。
- 页面未保存的表单仍只在内存中；刷新前应保留输入。来源编号校验不能保证模型语义分析正确，AI 百分比仍是估计。
- 每次查询重放并校验事件，尚无大数据量性能验收。活动日志保留发生时的目标关联，不因之后重新分配任务而重写历史。
- 备份是明文；密钥不可跨 Windows 账户直接复用。外部模型已收到请求后若本地进程中断，再次手动重试可能重复计费。
- 浏览器控制恢复后，优先补齐实际页面验收，再根据体验反馈调整布局。供应商配置后，先用虚构目标验收真实模型，再决定是否发送选中的个人资料。
