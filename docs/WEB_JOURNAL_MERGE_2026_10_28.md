# 记录页面合并与全内容查询 · 2026-10-28

## 已实现

- 导航收敛为总览、日志和想法、每日回顾、设置；扩展插件页面保留。
- 日志和想法集中录入、正式任务、想法库、记录修改待确认、历史查询及活动日志。原独立任务与想法页撤下，原数据和确认流程不变。
- 早中晚回顾移到每日回顾，与该页日期一致。保存或确认更正后刷新当天概述；保留来源与历史。
- 新增网页登录专用只读 `/api/history?q=&day=&kind=&offset=0&limit=30`。支持关键词、日期、内容类型、分页及旧修订匹配。返回当前标题、匹配版本、完整历史和记录编号。
- 搜索包含日常记录、任务、想法、目标、任务归属、活动日志、早中晚回应、个人资料、目标分析、定时报告、AI 建议和业务修改提案。
- 日期按记录日期或报告结束日期筛选；无业务日期的内容按上海时区更新时间筛选。旧修订也参与匹配，结果按记录归并。
- 搜索不读取磁盘任意文件，不纳入凭据、设备令牌、模型/服务配置、自动调用授权、已退役状态或任意第三方插件数据。新增插件类型须显式审核后接入查询，不自动暴露插件内部字段。
- 既有外部只读令牌及 APK/Agent 权限未扩大；未登录的服务器请求被拒绝。
