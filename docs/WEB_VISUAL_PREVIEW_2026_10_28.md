# 网页视觉第一轮：总览与公共导航

日期：2026-10-28。下文是第一轮历史记录；最新调整以 [第二轮记录](WEB_VISUAL_REVISION_2026_10_28.md) 为准。第二轮已按用户要求移除当前状态功能并调整页面，不再沿用本页的目标摘要和模块布局。

## 已确认方向与实现范围

- 中性极简：白色、浅灰、深灰正文；蓝色只强调目标进度，状态保留文字。
- 下一步行动在最前，快捷记录紧邻，目标进度摘要随后；完整模块仍遵守原排序和隐藏设置。
- 摘要最多展示前三个目标，使用原 dashboard 数据与 Progress 组件，可跳转到原目标详情；没有新增接口或请求，不混合 AI 估计与已确认进度，未知值仍未知。
- 去掉总览装饰图、大幅标题和模块序号；保留各功能入口、按钮处理函数、资料选择与确认流程。
- 改动集中在 `frontend/src/overview.css`、`Dashboard.tsx`、`main.tsx`；`trackingUI.tsx` 只将差异小标题从 h4 改为 h3，修正标题层级。其他页面沿用原内容样式，只共享本轮导航样式；后续再统一。

## 设计与检查依据

使用 design-taste-frontend 的 app-screen 流程，方向为 Achromatic ledger，seed `182486511`。保留中文系统字体，不新增远程字体请求。产品特征是“下一步行动 + 已确认进度 / AI 估计分栏”。

抽取的无侧栏方案及一次重抽的图标栏均不适合现有六个以上具名导航入口，因此按用户保留入口的约束采用带文字侧栏；平板/手机保留可直接点击的导航。未引入新路由或折叠菜单状态逻辑。

依据 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md) 检查本轮展示：增加跳到主内容、当前导航语义、统计分组语义；正文/元数据对比度、可见焦点、锚点留白、数字等宽、长内容换行、减少动态效果与窄屏布局。既有路由状态、表单保存策略等业务交互不在本轮改写，不宣称全项目全面符合该规范。
